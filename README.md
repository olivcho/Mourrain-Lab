# ViewPoint Sleep Behavior Analysis

A Python tool for analyzing zebrafish behavior using ViewPoint `.xlsx` data files.  
Originally written in MATLAB by Louis Leung, Ph.D., this version was re-written and extended in Python for speed, clarity, and to support additional analyses of sleep behavior.

---

## 📂 Project Structure

This script provides:
- Automated preprocessing and filtering of ViewPoint data
- Interactive GUI input for customizable analysis
- Generation of total activity, sleep, and sleep bout plots
- Exported summary `.xlsx` files
